Recommended photo instructions

Ask for a few clear photos of what the customer would like repaired. A wider view, close-up and different angles are useful suggestions. If intake was already captured by voice, request photos by reply after the call, with permission; do not send the full form again. Photos help prepare for an inspection and do not guarantee repairability or a final price.

You do not need to use every workflow or offer online scheduling. Before activation, record your choices with the person who handles your leads. Leave unwanted workflows in Draft and unwanted AI features Off. Keep a copy of the original configuration before editing.

One intake, then only missing information.

A missed call with no captured intake may receive the full intake form. When the voice assistant has already collected the details, it must save those details and ask only for anything missing or changed. If photo texts are enabled and the caller agrees, send a photo-only request after the call ends so the customer can reply with pictures. Do not send the same customer back through the full form.

Changing a feature that is already live

  1. Record the current configuration and return the affected workflows to Draft before changing them.
  2. Review Enrollment History and pending actions for those workflows. Remove affected contacts from obsolete sequences using the supported workflow controls; do not assume a Draft switch alone has cancelled every queued message.
  3. Update the related AI actions and instructions, public links, calendar availability, message copy and internal assignments.
  4. Run a controlled test for the enabled path and the disabled path. Check messages, bookings, staff alerts and pending actions before resuming live traffic.
Need help choosing or changing a feature? Use the AI chat for guide-based explanations. Human technical assistance is included only with Installed for You, within its 30-day scope. Do not share passwords or authentication codes. If a dependency or queued action is unclear, do not activate the affected feature.
